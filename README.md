# Smart Water Quality Analytics Dashboard

## Project Description

Analyzed simulated water-quality sensor data using Python and SQL, performed basic data cleaning, and created an interactive Power BI dashboard to visualize pH, turbidity, temperature, and water-quality status.

## Tools Used

- Python
- Pandas
- SQL / SQLite
- Power BI

## Dataset

The project uses a simulated dataset containing 1,000 water-quality sensor readings.

The dataset includes:

- pH
- Turbidity
- Temperature
- Timestamp
- Water-quality status

## Data Processing

- Checked missing values
- Checked duplicate records
- Performed basic data cleaning
- Calculated descriptive statistics
- Classified readings as Good, Warning, or Poor

## SQL Analysis

SQL was used to:

- Count total readings
- Calculate average measurements
- Analyze water-quality status
- Identify poor-quality readings

## Power BI Dashboard

The dashboard contains:

- Total readings
- Average pH
- Average turbidity
- Average temperature
- Water-quality status
- pH trend
- Turbidity trend
- Status filter

## Note

The sensor readings are simulated/sample data created for learning and analytics practice. They are not readings from a live deployed sensor system.
